# 🍳 Kin Yark (กินยาก) - Ingredients-Based Recipe Platform

โปรเจกต์รายวิชา **การพัฒนาโปรแกรมประยุกต์บนเว็บสำหรับวิศวกรรมซอฟต์แวร์ (Web Application Development for Software Engineering)** พัฒนาโดยกลุ่ม **KINYARK** สาขาวิศวกรรมซอฟต์แวร์ มหาวิทยาลัยพะเยา

เว็บไซต์คอมมูนิตี้และเครื่องมือช่วยค้นหาสูตรอาหารอัจฉริยะ ที่ช่วยเปลี่ยนวัตถุดิบเหลือใช้ในตู้เย็นของคุณให้กลายเป็นเมนูจานโปรด ด้วยระบบจับคู่และคัดสรรส่วนผสม พร้อมพลังขับเคลื่อนการแนะนำเมนูจาก AI และคอมมูนิตี้ผู้ใช้งาน

---

## 💡 ที่มา (Inspiration)
หลายครั้งที่ผู้คนเปิดตู้เย็นมาแล้วพบกับวัตถุดิบที่หลากหลายแต่ไม่รู้จะปรุงเป็นเมนูอะไรดี หรือบางครั้งข้อจำกัดด้านสุขภาพ เช่น อาการแพ้อาหาร หรือการเลือกทานอาหารเฉพาะกลุ่ม (เช่น มังสวิรัติ, ฮาลาล) ก็ทำให้การตัดสินใจเลือกเมนูในแต่ละวันกลายเป็นเรื่องยาก

กลุ่ม **KINYARK** จึงได้พัฒนาเว็บไซต์ **"KINYARK INGREDIENTS"** ขึ้นมา เพื่อช่วยแก้ปัญหาเหล่านี้ด้วยเทคโนโลยีดิจิทัล เปลี่ยนขั้นตอนการคิดเมนูให้เป็นเรื่องง่าย สนุก ลดการเหลือทิ้งของวัตถุดิบ (Zero Food Waste) และยังช่วยเชื่อมโยงผู้ใช้กับร้านค้าที่จัดจำหน่ายเซ็ทวัตถุดิบพร้อมปรุงอีกด้วย

---

## 🎯 วัตถุประสงค์ (Objectives)
- **Smart Ingredient Matching:** ช่วยให้ผู้ใช้เลือกวัตถุดิบที่มีอยู่ (เนื้อสัตว์, ผัก, ผลไม้, อาหารทะเล ฯลฯ) มาค้นหาสูตรอาหารที่ทำได้จริงทันที
- **AI & Community Synergy:** รวบรวมและแนะนำสูตรอาหารทั้งจากผู้ใช้งานในระบบ และสูตรแนะนำอัจฉริยะประจำสัปดาห์จาก AI (Gemini & DeepSeek)
- **Marketplace Integration:** เชื่อมโยงสูตรอาหารเข้ากับร้านค้า เพื่อนำเสนอ "เซ็ทวัตถุดิบพร้อมปรุง" ส่งตรงถึงบ้าน
- **Hyper-Personalization:** คัดกรองและปรับแต่งสูตรอาหารให้ตรงกับความต้องการของผู้ใช้ พร้อมระบบบันทึกเมนูโปรด (Favorites)

## 🛠️ Tech Stack (Tools)
- **Next.js (App Router)** – Framework ตัวหลักในการพัฒนาฝั่ง Frontend และรองรับการทำ Full-stack API Routes
- **Tailwind CSS v4** – สำหรับการเขียน Utility-First CSS ยุคใหม่ ดีไซน์หน้าเว็บให้ยืดหยุ่น (Responsive Design) และโหลดสไตล์ได้รวดเร็ว
- **TypeScript** – เพื่อเพิ่มประสิทธิภาพในการจัดการโครงสร้างข้อมูล พัฒนาโค้ดได้แม่นยำและลดข้อผิดพลาด
- **Supabase** – จัดการระบบ Authentication (เช่น การเข้าสู่ระบบ, รีเซ็ตรหัสผ่านผ่านอีเมล) และระบบ Storage สำหรับเก็บรูปภาพ
- **Prisma (ORM)** – ตัวกลางในการจัดการและเชื่อมต่อกับฐานข้อมูล (Database) อย่างเป็นระบบ
- **Playwright** – เครื่องมือทำ Automated End-to-End (E2E) Testing จำลองการทดสอบระบบอัตโนมัติ

## 📝 บทบาทผู้ใช้งาน (User Capabilities)

| บทบาท | คำอธิบาย |
| :--- | :--- |
| **Guest / User** | สามารถดูฟีดเมนูทั่วไป ค้นหาสูตรอาหารผ่านหมวดหมู่วัตถุดิบ และดูรายละเอียดสูตรอาหารได้ |
