### 6. กฎทางธุรกิจ (Business Rules)

- การเพิ่ม/ลบรายการโปรดเป็น Atomic Operation
- ระบบใช้ Unique Constraint ตรวจสอบความซ้ำ
- เมื่อเปลี่ยนสถานะโปรด ระบบจะล้างแคชที่เกี่ยวข้อง
- ผู้ใช้ต้องเข้าสู่ระบบก่อนเพิ่มรายการโปรด

### 7. อินเทอร์เฟซ (Interface Requirements)

| ประเภท | รายละเอียด |
|--------|-----------|
| Frontend | Next.js App Router |
| Backend | API Routes ใน Next.js |
| Database | PostgreSQL ผ่าน Prisma ORM |

### 8. ข้อจำกัด (Constraints)

- ผู้ใช้ต้องเข้าสู่ระบบก่อน
- สูตรต้องมีอยู่จริงในระบบ
- หนึ่งผู้ใช้หนึ่งสูตรมีได้เพียง 1 สถานะ

### 9. สมมติฐาน (Assumptions)

- ผู้ใช้ต้องการบันทึกสูตรที่ชอบ
- ระบบต้องอัปเดตจำนวนรายการโปรดเสมอ
