### 6. กฎทางธุรกิจ (Business Rules)

- ผู้ใช้ต้องเลือกวัตถุดิบอย่างน้อย 1 ชนิด
- สูตร AI จะถูกบันทึกเป็นสูตรจริงในระบบ
- ระบบใช้ System User (ai-system@kinyark.local) เป็นเจ้าของสูตร AI
- AI ไม่สร้างชื่อสูตรซ้ำกับที่มีอยู่
- ถ้า AI ตัวใดตัวหนึ่งล้มเหลว ระบบยังทำงานได้

### 7. อินเทอร์เฟซ (Interface Requirements)

| ประเภท | รายละเอียด |
|--------|-----------|
| Frontend | Next.js App Router |
| Backend | API Routes ใน Next.js |
| AI Provider | Google Gemini, Groq (OpenAI), DeepSeek |
| Image Generator | Pollinations.ai |
| Database | PostgreSQL ผ่าน Prisma ORM |

### 8. ข้อจำกัด (Constraints)

- ต้องมี API Key สำหรับผู้ให้บริการ AI
- ทุกสูตรต้องมีเจ้าของจริง
- คำตอบจาก AI ต้องเป็น JSON ที่ถูกต้อง
- ปริมาณวัตถุดิบต้องเป็นตัวเลข

### 9. สมมติฐาน (Assumptions)

- ผู้ใช้มีวัตถุดิบให้เลือก
- API Key ของ AI Provider ถูกตั้งค่าเรียบร้อย
- ผู้ใช้ต้องการสูตรอาหารที่สร้างโดย AI
- Pollinations.ai สามารถสร้างรูปภาพได้
