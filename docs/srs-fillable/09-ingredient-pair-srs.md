### 6. กฎทางธุรกิจ (Business Rules)

- ชุดวัตถุดิบจะถูกจัดเรียงและทำให้เป็น lowercase
- แต่ละคู่วัตถุดิบจะได้สูตรจาก AI 2 ตัว (Gemini + Groq)
- แคชจะหมดอายุรายเดือน
- AI ไม่สร้างชื่อสูตรซ้ำกับที่มีในระบบ
- ระบบจะคืนสูตรเดิมหากมีแคชในเดือนนี้

### 7. อินเทอร์เฟซ (Interface Requirements)

| ประเภท | รายละเอียด |
|--------|-----------|
| Frontend | Next.js App Router |
| Backend | API Routes ใน Next.js |
| AI Provider | Google Gemini, Groq |
| Image Generator | Pollinations.ai |
| Database | PostgreSQL ผ่าน Prisma ORM |

### 8. ข้อจำกัด (Constraints)

- ต้องเลือกวัตถุดิบอย่างน้อย 1 ชนิด
- ต้องมี API Key สำหรับ AI Provider
- ระบบใช้ System User เป็นเจ้าของสูตร
- ชื่อสูตรต้องไม่ซ้ำกับที่มีอยู่

### 9. สมมติฐาน (Assumptions)

- ผู้ใช้ต้องการสูตรจากวัตถุดิบที่เลือก
- วัตถุดิบที่เลือกเป็นภาษาไทย
- ระบบสามารถเรียก AI ได้
