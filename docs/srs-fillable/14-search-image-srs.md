### 6. กฎทางธุรกิจ (Business Rules)

- ระบบค้นหาจาก Wikimedia Commons เท่านั้น
- คืนรูปภาพสูงสุด 4 รูปต่อการค้นหา 1 ครั้ง
- ค่าเริ่มต้นคือ 'thai food' หากไม่ระบุคำค้นหา

### 7. อินเทอร์เฟซ (Interface Requirements)

| ประเภท | รายละเอียด |
|--------|-----------|
| Frontend | Next.js App Router |
| Backend | API Routes ใน Next.js |
| External API | Wikimedia Commons API |

### 8. ข้อจำกัด (Constraints)

- ต้องมีการเชื่อมต่ออินเทอร์เน็ต
- ใช้ Wikimedia Commons namespace 6 (File)

### 9. สมมติฐาน (Assumptions)

- ผู้ใช้ต้องการหารูปภาพอาหาร
- Wikimedia Commons API ใช้งานได้
