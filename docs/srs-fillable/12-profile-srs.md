### 6. กฎทางธุรกิจ (Business Rules)

- ชื่อผู้ใช้ต้องไม่ซ้ำกัน
- โปรไฟล์แคช 30 วินาที (ไม่แคชในสภาพแวดล้อมทดสอบ)
- ระบบรับรองผู้ใช้ผ่าน Supabase ก่อนแสดงโปรไฟล์
- ผู้ใช้สามารถอัปเดตได้เฉพาะตัวเองเท่านั้น

### 7. อินเทอร์เฟซ (Interface Requirements)

| ประเภท | รายละเอียด |
|--------|-----------|
| Frontend | Next.js App Router |
| Backend | API Routes ใน Next.js |
| Database | PostgreSQL ผ่าน Prisma ORM |
| Authentication | Supabase Auth |
| Storage | Supabase Storage |

### 8. ข้อจำกัด (Constraints)

- ผู้ใช้ต้องเข้าสู่ระบบก่อน
- ชื่อผู้ใช้ต้องไม่ซ้ำ
- ไม่แคชโปรไฟล์ในสภาพแวดล้อมทดสอบ

### 9. สมมติฐาน (Assumptions)

- ผู้ใช้ต้องการแก้ไขโปรไฟล์
- Supabase Auth ทำงานได้
