### 6. กฎทางธุรกิจ (Business Rules)

- สัปดาห์ละ 8 สูตร (4 ฤดูกาล + 4 ยอดนิยม)
- สูตรรายสัปดาห์จะถูกแคชจนกว่าจะถึงสัปดาห์ถัดไป
- ใช้ Gemini สำหรับสูตรฤดูกาล, Groq สำหรับสูตรยอดนิยม
- ระบบจะสร้างสูตรใหม่ก็ต่อเมื่อยังไม่มีในสัปดาห์นี้
- วัตถุดิบตามฤดูกาลจะถูกกรองให้เหลือเฉพาะที่มีจริงใน DB

### 7. อินเทอร์เฟซ (Interface Requirements)

| ประเภท | รายละเอียด |
|--------|-----------|
| Frontend | Next.js App Router |
| Backend | API Routes ใน Next.js |
| AI Provider | Google Gemini (seasonal), Groq (trending) |
| Image Generator | Pollinations.ai |
| Database | PostgreSQL ผ่าน Prisma ORM |

### 8. ข้อจำกัด (Constraints)

- ต้องมี API Key สำหรับ Gemini และ Groq
- ระบบใช้ System User เป็นเจ้าของสูตร
- ต้องมีวัตถุดิบจริงอย่างน้อยบางส่วนใน DB

### 9. สมมติฐาน (Assumptions)

- ผู้ใช้ต้องการสูตรแนะนำรายสัปดาห์
- ฐานข้อมูลมีวัตถุดิบให้เลือก
- API ของ AI Provider พร้อมใช้งาน
