### 6. กฎทางธุรกิจ (Business Rules)

- ชื่อวัตถุดิบต้องไม่ซ้ำกันในระบบ
- ชื่อหมวดหมู่ต้องไม่ซ้ำกัน
- วัตถุดิบจะถูกสร้างอัตโนมัติเมื่อไม่มีในชื่อสูตร
- การค้นหาวัตถุดิบเป็นแบบ case-insensitive

### 7. อินเทอร์เฟซ (Interface Requirements)

| ประเภท | รายละเอียด |
|--------|-----------|
| Frontend | Next.js App Router |
| Backend | API Routes ใน Next.js |
| Database | PostgreSQL ผ่าน Prisma ORM |

### 8. ข้อจำกัด (Constraints)

- ชื่อวัตถุดิบต้องไม่ว่างเปล่า
- ชื่อวัตถุดิบสูงสุด 120 ตัวอักษร
- ระบบสร้างหมวดหมู่ใหม่อัตโนมัติเมื่อไม่มีหมวดหมู่นั้น

### 9. สมมติฐาน (Assumptions)

- วัตถุดิบส่วนใหญ่เป็นภาษาไทย
- ผู้ใช้สามารถเพิ่มวัตถุดิบใหม่ได้
- ระบบมีรายการวัตถุดิบเริ่มต้น
