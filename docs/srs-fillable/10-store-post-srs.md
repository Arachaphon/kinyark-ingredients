### 5. โครงสร้างข้อมูล (Data Requirements)

| ชื่อตาราง | คำอธิบาย | ฟิลด์หลัก |
|-----------|---------|---------|
| store_posts | โพสต์ร้านค้า | id, userId, recipeId, storeName, sellingPrice, storeDescription, storeLocation, contactInfo, visibility, setIngredients, createdAt |
| store_post_images | รูปภาพโพสต์ | id, storePostId, imageUrl |
| store_post_videos | วิดีโอโพสต์ | id, storePostId, videoUrl |

### 6. กฎทางธุรกิจ (Business Rules)

- เจ้าของโพสต์เท่านั้นที่สามารถลบโพสต์ได้
- โพสต์ที่ไม่เชื่อมกับสูตรก็แสดงในผลการค้นหาได้
- สถานะ draft ไม่แสดงในผลการค้นหา
- เมื่อลบโพสต์จะลบรูปภาพและวิดีโอออกจาก storage ด้วย

### 7. อินเทอร์เฟซ (Interface Requirements)

| ประเภท | รายละเอียด |
|--------|-----------|
| Frontend | Next.js App Router |
| Backend | API Routes ใน Next.js |
| Database | PostgreSQL ผ่าน Prisma ORM |
| Storage | Supabase Storage |

### 8. ข้อจำกัด (Constraints)

- ต้องมีผู้ใช้เข้าสู่ระบบ
- ชื่อร้านค้าต้องไม่ว่างเปล่า
- ราคาต้องไม่ติดลบ
- เจ้าของโพสต์เท่านั้นที่ลบได้

### 9. สมมติฐาน (Assumptions)

- ผู้ค้าต้องการลงโพสต์สินค้า
- ระบบมี Supabase Storage สำหรับเก็บไฟล์
