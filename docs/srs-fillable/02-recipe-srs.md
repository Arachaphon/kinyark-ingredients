### 6. กฎทางธุรกิจ (Business Rules)

- สูตรอาหารต้องมีเจ้าของ (userId) เสมอ
- สถานะ draft จะไม่แสดงในผลการค้นหา
- สูตรที่สร้างโดย AI จะมี aiProvider ระบุ
- ระบบจะตัดสินใจเลือกใช้ AI หรือไม่เมื่อสร้างสูตร

### 7. อินเทอร์เฟซ (Interface Requirements)

| ประเภท | รายละเอียด |
|--------|-----------|
| Frontend | Next.js App Router |
| Backend | API Routes ใน Next.js |
| Database | PostgreSQL ผ่าน Prisma ORM |
| Storage | Supabase Storage (รูปภาพ, วิดีโอ) |

### 8. ข้อจำกัด (Constraints)

- ทุกสูตรต้องมีผู้เป็นเจ้าของ
- ส่วนผสมต้องมีอย่างน้อย 1 รายการ
- ชื่อสูตรต้องไม่ซ้ำกับสูตรที่มีอยู่

### 9. สมมติฐาน (Assumptions)

- ผู้ใช้สามารถอัปโหลดรูปภาพและวิดีโอได้
- ระบบสามารถเชื่อมต่อกับ AI Provider ได้
- ฐานข้อมูล PostgreSQL สามารถใช้งานได้ตลอดเวลา
