### 6. กฎทางธุรกิจ (Business Rules)

- การค้นหาแบบ strict จะไม่พบผลลัพธ์ก็จะใช้ bigram matching
- สถานะ draft จะไม่แสดงในผลการค้นหา
- ผลการค้นหาจำกัด 50 รายการสูตร + 50 รายการร้านค้า
- สถานะ protected แสดงเฉพาะผู้ใช้ที่เข้าสู่ระบบ

### 7. อินเทอร์เฟซ (Interface Requirements)

| ประเภท | รายละเอียด |
|--------|-----------|
| Frontend | Next.js App Router |
| Backend | API Routes ใน Next.js |
| Database | PostgreSQL ผ่าน Prisma ORM |

### 8. ข้อจำกัด (Constraints)

- คำค้นหาต้องมีอย่างน้อย 2 ตัวอักษรสำหรับ bigram matching
- ผลลัพธ์สูงสุด 50 รายการต่อคำค้นหา
- ข้อมูลที่ค้นหาต้องไม่ละเมิดสิทธิ์การเข้าถึง

### 9. สมมติฐาน (Assumptions)

- ผู้ใช้ค้นหาด้วยภาษาไทยและภาษาอังกฤษ
- ระบบมีวัตถุดิบและสูตรอาหารเพียงพอ
- ฐานข้อมูลมีดัชนีสำหรับการค้นหาอย่างมีประสิทธิภาพ
