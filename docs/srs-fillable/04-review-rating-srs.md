### 6. กฎทางธุรกิจ (Business Rules)

- ผู้ใช้หนึ่งคนรีวิวสูตรเดียวได้เพียง 1 ครั้ง
- คะแนนเฉลี่ยจะถูกอัปเดตอัตโนมัติเมื่อมีรีวิวใหม่
- คะแนนปัดเศษทศนิยม 1 ตำแหน่ง
- รีวิวจะถูกลบเมื่อลบสูตร (Cascade Delete)

### 7. อินเทอร์เฟซ (Interface Requirements)

| ประเภท | รายละเอียด |
|--------|-----------|
| Frontend | Next.js App Router |
| Backend | API Routes ใน Next.js |
| Database | PostgreSQL ผ่าน Prisma ORM |

### 8. ข้อจำกัด (Constraints)

- ผู้ใช้ต้องเข้าสู่ระบบก่อนรีวิว
- คะแนนต้องเป็นจำนวนเต็ม 1-5
- หนึ่งคนหนึ่งสูตรรีวิวได้ครั้งเดียว

### 9. สมมติฐาน (Assumptions)

- ผู้ใช้สามารถให้คะแนนและแสดงความคิดเห็นได้
- ระบบติดตามจำนวนรีวิวและคะแนนเฉลี่ย
