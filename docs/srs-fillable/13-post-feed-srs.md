### 6. กฎทางธุรกิจ (Business Rules)

- การกด Like ใช้ Optimistic UI (เปลี่ยนทันที)
- ถ้า API ล้มเหลว ระบบจะยกเลิกการเปลี่ยนแปลง
- แสดงสูงสุด 10 สูตรต่อหน้า
- แยกประเภทโพสต์: ทั้งหมด, ผู้ใช้, AI

### 7. อินเทอร์เฟซ (Interface Requirements)

| ประเภท | รายละเอียด |
|--------|-----------|
| Frontend | Next.js App Router (Client Component) |
| Backend | API Routes ใน Next.js |
| Data Fetching | useSWR |
| Font | Anuphan (Thai font) |

### 8. ข้อจำกัด (Constraints)

- ใช้ SWR สำหรับการดึงข้อมูล
- ผู้ใช้ต้องเข้าสู่ระบบก่อนกด Like
- แสดงสูงสุด 10 รายการต่อหน้า

### 9. สมมติฐาน (Assumptions)

- ผู้ใช้ต้องการดูฟีดชุมชน
- ผู้ใช้มีสูตรที่กด Like
