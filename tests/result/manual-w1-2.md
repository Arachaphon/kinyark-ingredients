# รายงานผลการทดสอบระบบ (Manual Test Results) - W1-2 Get Recipe

## 🟢 Positive Test Cases

### 1. เข้าถึงและแสดงรายละเอียดสูตรอาหารได้อย่างสมบูรณ์ (จากทุกจุดที่เข้าถึงได้)
**วิธีทดสอบ (Steps):**
1. ล็อกอินเข้าสู่ระบบ
2. กดเข้าไปดูสูตรอาหาร 1 สูตรจากแต่ละหน้าต่อไปนี้:
   - หน้า "โพสต์ทั้งหมด" (หน้าหลัก)
   - หน้า "รายการโปรด" (ถ้ามีการกดถูกใจไว้)
   - หน้า "สูตรอาหารของฉัน" (ในหน้า Profile ตัวเอง)
3. เมื่อหน้าโหลดเสร็จ ให้ตรวจสอบข้อมูลบนหน้าจอ

**ผลที่คาดหวัง (Expected Results):**
- [ ] ระบบพาไปยังหน้ารายละเอียดสูตรอาหารได้ถูกต้องจากทุกๆ ช่องทาง โดยไม่มีหน้าจอขาว (Crash)
- [ ] ชื่อสูตรอาหาร, ภาพปก, วิดีโอ (ถ้ามี), คำอธิบาย แสดงผลครบถ้วน
- [ ] แสดงข้อมูลชื่อผู้เขียน และรูปภาพผู้เขียน
- [ ] รายการส่วนผสมแสดงครบ พร้อมระบุหมวดหมู่ ปริมาณ และหน่วยที่ถูกต้อง (เช่น เนื้อหมู 200 กรัม)
- [ ] วิธีทำและอุปกรณ์ทำอาหารแสดงผลครบถ้วน
- [ ] หากเป็นสูตรของ "ร้านค้า" จะต้องมีกล่องข้อมูลร้านค้า (ชื่อร้าน, ราคา, รูปเซ็ตวัตถุดิบ, ช่องทางการติดต่อ) แสดงขึ้นมาด้วย

---

### 2. การจัดการสถานะถูกใจ (Favorite/Like) บนสูตรอาหาร
**วิธีทดสอบ (Steps):**
1. เปิดหน้ารายละเอียดสูตรอาหาร
2. กดไอคอน "รูปหัวใจ" เพื่อบันทึกเป็นรายการโปรด
3. สังเกตตัวเลขยอดถูกใจ
4. กดไอคอน "รูปหัวใจ" อีกครั้งเพื่อเลิกถูกใจ
5. สังเกตตัวเลขยอดถูกใจ

**ผลที่คาดหวัง (Expected Results):**
- [ ] เมื่อกดถูกใจ: ไอคอนหัวใจเปลี่ยนเป็นสีแดง และตัวเลขจำนวนไลก์เพิ่มขึ้น 1
- [ ] เมื่อกดเลิกถูกใจ: ไอคอนหัวใจกลับมาเป็นปกติ และตัวเลขจำนวนไลก์ลดลง 1
- [ ] หากกด Refresh หน้าจอ สถานะการกดถูกใจจะต้องยังคงอยู่เหมือนเดิม (Persisted)

---

### 3. เจ้าของสูตรสามารถเข้าดูสูตรแบบ "ส่วนตัว (Private)" ได้
**วิธีทดสอบ (Steps):**
1. ล็อกอินด้วยบัญชีที่เป็นเจ้าของสูตรที่ถูกตั้งสถานะเป็น "Private" หรือ "ฉบับร่าง"
2. ไปที่หน้าโปรไฟล์ของตนเอง
3. กดคลิกดูรายละเอียดของสูตรที่เป็น Private นั้น

**ผลที่คาดหวัง (Expected Results):**
- [ ] ระบบอนุญาตให้เจ้าของเข้าดูสูตรอาหารของตนเองได้ตามปกติ
- [ ] ข้อมูลทุกอย่างแสดงครบถ้วนเหมือนสูตรปกติ

---

## 🔴 Negative Test Cases

### 4. ไม่สามารถเข้าถึงข้อมูลสูตรอาหารหากไม่ได้รับอนุญาตหรือข้อมูลไม่มีอยู่จริง
**วิธีทดสอบ (Steps):**
1. **ทดสอบ URL ที่ไม่มีจริง:** พิมพ์ URL หน้ารายละเอียดสูตรที่เป็น UUID มั่วๆ หรือใช้ ID ของสูตรที่ถูกลบไปแล้ว
2. **ทดสอบละเมิดสิทธิ์ (Private):** ให้ User A สร้างสูตรแบบ Private จากนั้นก็อปปี้ URL ไปให้ User B (หรือโหมด Incognito) ลองเปิดดู
3. **ทดสอบแบบไม่ล็อกอิน (Guest):** นำลิงก์สูตร Public ไปเปิดในหน้าต่างที่ยังไม่ได้ล็อกอิน

**ผลที่คาดหวัง (Expected Results):**
- [ ] กรณี URL มั่ว หรือสูตรถูกลบไปแล้ว: ระบบต้องแสดงข้อความ "ไม่พบสูตรอาหารนี้" และหน้าเว็บต้องไม่พัง (No Crash/White Screen)
- [ ] กรณีเปิดสูตร Private ของคนอื่น: ระบบต้องไม่อนุญาตให้ดู และแสดงหน้า "ไม่พบสูตรอาหารนี้" เพื่อปกป้องข้อมูลส่วนตัว
- [ ] กรณีเข้าดูแบบไม่ล็อกอิน (Guest): ระบบควรจะบังคับ Redirect กลับไปยังหน้า `/login` ทันที ไม่อนุญาตให้อ่านเนื้อหา (ตาม Business Logic ของแอป)
