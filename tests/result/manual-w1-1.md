# รายงานผลการทดสอบระบบ (Manual Test Results) - W1-1 Create Recipe

**วันที่ทดสอบ:** 28 กรกฎาคม 2026

**สถานะ:** ⏳ รอการทดสอบ (Pending)

---

## รายการทดสอบ

### [/] 1. สร้างสูตรอาหารด้วยข้อมูลที่ถูกต้อง

**วิธีทดสอบ**
- ล็อกอินเข้าสู่ระบบ
- เรียก API Create Recipe
- ส่งข้อมูลสูตรอาหารและวัตถุดิบให้ครบถ้วน

**ผลที่คาดหวัง**
- ได้รับ Status **201 Created**
- ระบบสร้างสูตรอาหารสำเร็จ
- ข้อมูลถูกบันทึกลงฐานข้อมูลครบทุกตารางที่เกี่ยวข้อง

---

### [/] 2. สร้างสูตรอาหารโดยไม่ได้ล็อกอิน

**วิธีทดสอบ**
- เรียก API Create Recipe โดยไม่ส่ง Session หรือ Token

**ผลที่คาดหวัง**
- ได้รับ Status **401 Unauthorized**
- ระบบไม่อนุญาตให้สร้างสูตรอาหาร

---

### [ ] 3. สร้างสูตรอาหารโดยส่งข้อมูลไม่ครบ

**วิธีทดสอบ**
ลองส่งข้อมูลที่ไม่ถูกต้อง เช่น
- ไม่มีชื่อสูตรอาหาร
- ไม่มีส่วนผสม
- ข้อมูลไม่ผ่าน Validation

**ผลที่คาดหวัง**
- ได้รับ Status **400 Bad Request**
- ระบบแจ้ง Validation Error
- ไม่มีข้อมูลถูกบันทึกลงฐานข้อมูล

---

### [ ] 4. จำลองกรณีฐานข้อมูลเกิดข้อผิดพลาดก่อนเริ่มบันทึกข้อมูล

**วิธีทดสอบ**
- จำลองให้ฐานข้อมูลเกิด Error ก่อนเริ่ม Transaction

**ผลที่คาดหวัง**
- ได้รับ Status **500 Internal Server Error**
- ไม่มีข้อมูลถูกบันทึกลงฐานข้อมูล

---

### [ ] 5. จำลองกรณีฐานข้อมูลเกิดข้อผิดพลาดระหว่างบันทึกข้อมูล

**วิธีทดสอบ**
- จำลองให้เกิด Error ระหว่าง Transaction

**ผลที่คาดหวัง**
- ได้รับ Status **500 Internal Server Error**
- ระบบ Rollback Transaction
- ไม่มีข้อมูลใดถูกบันทึกลงฐานข้อมูล
