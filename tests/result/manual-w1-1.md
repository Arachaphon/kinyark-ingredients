# รายงานผลการทดสอบระบบ (Manual Test Results) - W1-1 Create Recipe

## 🟢 Positive Test Cases

### 1. User สร้างสูตรอาหารแบบครบถ้วน (รวมภาพ วิดีโอ อุปกรณ์ และตั้งค่าการมองเห็น)
**วิธีทดสอบ (Steps):**
1. ล็อกอินเข้าสู่ระบบด้วยบัญชี User ทั่วไป
2. ไปที่เมนู "สร้างสูตรอาหาร"
3. กรอกชื่อสูตรอาหาร และคำอธิบาย
4. อัปโหลดรูปภาพปก (อย่างน้อย 1 รูป) และวิดีโอ (ตัวเลือก)
5. เพิ่มวัตถุดิบ 2-3 รายการ (ระบุชื่อ, หมวดหมู่, ปริมาณ, หน่วย)
6. เพิ่มอุปกรณ์ทำอาหาร
7. กรอกวิธีทำ
8. เลือกสถานะเป็น "สาธารณะ (Public)" หรือ "ส่วนตัว (Private)"
9. กดปุ่ม "เผยแพร่เมนูอาหาร" หรือ "บันทึกฉบับร่าง"

**ผลที่คาดหวัง (Expected Results):**
- [ ] ระบบบันทึกสูตรอาหารสำเร็จ และแจ้งเตือนความสำเร็จ
- [ ] หากเลือกเผยแพร่ ระบบพาไปหน้ารายละเอียดสูตรอาหาร หรือหน้ารวมสูตร
- [ ] ข้อมูลชื่อสูตร คำอธิบาย วัตถุดิบ และวิธีทำ แสดงตรงตามที่กรอก
- [ ] รูปภาพปกและวิดีโอสามารถแสดงผล/เล่นได้ตามปกติ
- [ ] สถานะการมองเห็น (Public/Private) ถูกจัดเก็บถูกต้องตามที่เลือก

---

### 2. ร้านค้า (Store) สร้างสูตรอาหารพร้อมข้อมูลสำหรับขายเซ็ตวัตถุดิบ
**วิธีทดสอบ (Steps):**
1. ล็อกอินเข้าสู่ระบบด้วยบัญชีที่เปิดโหมดร้านค้า (Store)
2. ไปที่เมนู "สร้างสูตรอาหาร"
3. เลือกแถบ "ร้านค้า" ด้านบน
4. กรอกข้อมูลสูตรอาหารพื้นฐานให้ครบ
5. เลื่อนมาที่ส่วน "ข้อมูลร้านค้า" และกรอก ชื่อร้านค้า, ราคาขาย, คำอธิบายเซ็ต
6. กรอก "ช่องทางการติดต่อร้านค้า" และอัปโหลดรูปภาพวัตถุดิบ
7. กดปุ่ม "เผยแพร่เมนูอาหาร"

**ผลที่คาดหวัง (Expected Results):**
- [ ] ระบบบันทึกสูตรอาหารในฐานะร้านค้าสำเร็จ
- [ ] แสดงรายละเอียดของร้านค้า (ชื่อ ราคา ช่องทางติดต่อ) บนหน้ารายละเอียดสูตร
- [ ] รูปภาพเซ็ตวัตถุดิบของร้านค้าแสดงผลถูกต้องตามที่อัปโหลด

---

### 3. การดึงสูตรอาหารจากระบบ (System Recipe) แบบอัตโนมัติ
**วิธีทดสอบ (Steps):**
1. ไปที่เมนู "สร้างสูตรอาหาร"
2. ในส่วน "เพิ่มส่วนผสม" ให้พิมพ์ค้นหาวัตถุดิบ (เช่น "พริก", "หมู")
3. ระบบจะแสดงรายการสูตรแนะนำขึ้นมา ให้กดปุ่ม "เลือก" ที่สูตรใดสูตรหนึ่ง
4. ตรวจสอบข้อมูลในฟอร์ม จากนั้นกด "ยกเลิก"

**ผลที่คาดหวัง (Expected Results):**
- [ ] เมื่อกด "เลือก": ชื่อสูตร, วัตถุดิบ, และวิธีทำ จะถูกดึงมาเติมในฟอร์มให้อัตโนมัติและถูกต้อง
- [ ] เมื่อพิมพ์ "พริก" ระบบต้องแยกแยะคำว่า "พริกไทย" ได้อย่างถูกต้อง (ถ้าระบบรองรับการกรองคำนี้)
- [ ] เมื่อกด "ยกเลิก": ฟอร์ม (ชื่อ, วัตถุดิบ, วิธีทำ) จะต้องถูกเคลียร์กลับเป็นค่าเริ่มต้นทั้งหมด ไม่ทิ้งข้อมูลค้างไว้

## 🔴 Negative Test Cases

### 4. การตรวจสอบความถูกต้องของฟอร์ม (Form Validation) ในรอบเดียว
**วิธีทดสอบ (Steps):**
1. ล็อกอินเข้าสู่ระบบและไปที่เมนู "สร้างสูตรอาหาร"
2. กดปุ่ม "เผยแพร่เมนูอาหาร" หรือ "บันทึกฉบับร่าง" โดยปล่อยฟอร์มว่างเปล่าทั้งหมด
3. ทยอยกรอกข้อมูลทีละช่อง แล้วกดบันทึกซ้ำเพื่อดูการทำงานของ Error
4. กรณีร้านค้า: ลองปล่อยช่อง "ช่องทางการติดต่อร้านค้า" ทิ้งไว้แล้วกดบันทึก
5. ในช่องวัตถุดิบ ลองพิมพ์ชื่อวัตถุดิบที่มีในระบบ (เช่น "กะเพรา") แต่จงใจเลือกหมวดหมู่ให้ผิดจากความจริง (เช่น "เนื้อสัตว์")

**ผลที่คาดหวัง (Expected Results):**
- [ ] ระบบไม่บันทึกข้อมูลหากกรอกฟอร์มที่จำเป็นไม่ครบ
- [ ] มีกล่องแจ้งเตือน Error สีแดงแสดงอยู่ด้านบนของปุ่มกดบันทึก
- [ ] ช่องที่ไม่ได้กรอกจะถูกไฮไลท์ด้วยเส้นขอบสีแดง (Border ขนาด 1px) พร้อมพื้นหลังสีแดงอ่อน
- [ ] ระบบเลื่อนหน้าจอ (Scroll) ไปยังช่องแรกที่ยังไม่ได้กรอกโดยอัตโนมัติ
- [ ] กรณีร้านค้า: หากไม่กรอกช่องทางการติดต่อ จะต้องติด Required และขึ้นกรอบแดง
- [ ] กรณีกรอกหมวดหมู่วัตถุดิบผิด: เมื่อคลิกออกหรือบันทึก จะต้องมี Modal แจ้งเตือนว่าหมวดหมู่ขัดแย้งกับ Database

### 5. การจำกัดสิทธิ์การเข้าใช้งาน (Unauthorized Access)
**วิธีทดสอบ (Steps):**
1. เปิดเบราว์เซอร์โหมดไม่ระบุตัวตน (Incognito) โดยไม่ล็อกอิน
2. พิมพ์ URL เข้าสู่หน้า `/create-recipe` โดยตรง

**ผลที่คาดหวัง (Expected Results):**
- [ ] ระบบไม่อนุญาตให้เห็นฟอร์มสร้างสูตรอาหาร
- [ ] ระบบทำการ Redirect ผู้ใช้กลับไปยังหน้า Login ทันที
