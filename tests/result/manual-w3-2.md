## การทดสอบแบบ Manual (Authorization & Role Management)
ทดสอบการทำงานของระบบ Roles (USER, STORE, ADMIN) และการจำกัดสิทธิ์ในส่วนของการสร้างสูตรอาหาร (Store Recipe)

- [ ] **1. การลงทะเบียนในฐานะคนทั่วไป (USER)**
  - **Expected:** สามารถเลือกลงทะเบียนเป็น "คนทั่วไป" ได้สำเร็จ ระบบบันทึก role เป็น "USER" ในฐานข้อมูล

- [ ] **2. การลงทะเบียนในฐานะร้านค้า (STORE)**
  - **Expected:** สามารถเลือกลงทะเบียนเป็น "ร้านค้า" ได้สำเร็จ ระบบบันทึก role เป็น "STORE" ในฐานข้อมูล

- [ ] **3. การลงทะเบียนโดยพยายามสวมรอยเป็น ADMIN (ผ่าน API / Payload)**
  - **Expected:** ไม่สามารถลงทะเบียนได้ ระบบตอบกลับเป็น Validation Error เนื่องจากไม่อนุญาตให้เลือก role เป็น "admin" ผ่านช่องทางสาธารณะ

- [ ] **4. สิทธิ์ของ USER บนหน้า Create Recipe**
  - **Expected:** เมื่อล็อกอินด้วยบัญชีที่ได้ role เป็น "USER" จะไม่เห็นปุ่มหรือตัวเลือก "ร้านค้า" ในหน้าสร้างสูตรอาหาร

- [ ] **5. สิทธิ์ของ STORE บนหน้า Create Recipe**
  - **Expected:** เมื่อล็อกอินด้วยบัญชีที่ได้ role เป็น "STORE" จะมองเห็นและสามารถสลับตัวเลือกไปยัง "ร้านค้า" เพื่อกรอกข้อมูลร้านและอัปโหลดเมนูร้านได้

- [ ] **6. สิทธิ์ของ ADMIN บนหน้า Create Recipe**
  - **Expected:** เมื่อล็อกอินด้วยบัญชีที่ได้ role เป็น "ADMIN" (ถูกสร้างแบบ manual ในฐานข้อมูล) จะมองเห็นและสามารถสลับตัวเลือกไปยัง "ร้านค้า" เพื่อใช้งานฟีเจอร์ของร้านค้าได้

- [ ] **7. ตรวจสอบการทำงานของฟีเจอร์เดิม (Existing functionality)**
  - **Expected:** ฟีเจอร์สร้างสูตรอาหารแบบ "คนทั่วไป" ยังคงสามารถกรอกข้อมูล, อัปโหลดรูปภาพ, และบันทึกข้อมูลได้ตามปกติ ไม่มีผลกระทบจากการปรับปรุง Role
